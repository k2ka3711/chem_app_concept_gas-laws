- 変化前・変化後の2つの図を並べ、ボイル・シャルル・アボガドロの各法則と状態方程式を切り替えて比較できるUIを追加
- 変わる量・一定の量・関係式を視覚的に表示し、図を見比べる短い確認問題を追加

## [ver.1.0.2] — 2026-08-12 10:53 JST

- 問題の選択肢と問題セットのボタンを押しやすい大きさに調整

## [ver.1.0.1] — 2026-08-12 01:31 JST

### 学習体験の強化

### 気体シミュレーターを刷新

- 容器 A と容器 B を並べて比較できる「2容器比較」機能を追加
- 容器内の気体分子が移動し、壁に当たると跳ね返るアニメーションに変更
- 体積・温度・物質量をスライダーで操作できる機能を維持・改善
- 物質量の値に合わせて、画面内に表示される分子数が変化するように修正
- 温度に応じて分子の移動速度が変化するように対応

### 練習問題を拡充

- 3種類の問題セットを追加

- 一度に解く問題数を5問に設定し、初学者が集中して取り組みやすい構成に変更
- 各問題で正誤と解説をすぐに確認できるフィードバック機能を追加

### 表示・操作性の改善

- 問題セットを選択できるメニューを追加
- モバイル画面でも操作しやすいレイアウトに調整
- 学習進捗の表示を維持し、理解チェック・問題演習と連動
